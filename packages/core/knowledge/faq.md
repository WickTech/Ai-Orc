# FAQ

Operator only drafts a Gmail reply when a thread matches one of the entries
below (never one tagged `[EXAMPLE]`) and uses only the facts in that entry.
Replace the three example entries with your own before relying on Operator.
Keep the `## FAQ-NNN` / `**Keywords:**` / `**Answer:**` shape so the prompt
can parse entries reliably.

## FAQ-001 [EXAMPLE]: What are your support hours?
**Keywords:** support hours, availability, when do you reply
**Answer:** Support requests are answered within 2 business days, Monday to
Friday, 09:00–18:00 IST.

## FAQ-002 [EXAMPLE]: Do you offer a free trial?
**Keywords:** free trial, trial period, demo access
**Answer:** Every plan includes a 14-day free trial. No credit card is
required to start it.

## FAQ-003 [EXAMPLE]: Where can I find the API documentation?
**Keywords:** api docs, documentation, developer docs
**Answer:** API documentation lives at docs.example.com/api and is updated
with every release.
